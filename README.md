# Audio and Text Modder For Helldivers 2

- For original README, please read [here](https://github.com/RaidingForPants/hd2-audio-modder)

## Summary

- This is a heavily modified fork is geared toward my personal automated workflow.
- What make this fork difference that the main are the following:
  - audio files target import automation
  - automated patch generation
  - editing encoded sound bank data via external python scripts
  - high concurrent IO 
- This fork can be viewed as an proofing ground for future features that will be merged into
  the main repo.
- Companion repos
  - [Audio Asset Database](https://github.com/Dekr0/hd2_audio_db/tree/redesign)
  - [Wwise Teller](https://github.com/Dekr0/wwise-teller) - Wwise Teller intends to cover
    the lack of editing encoded sound bank data in a robust and fast manner.
